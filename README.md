# 새잎노트

사무실 식물을 혼자 관리하기 위한 작은 웹앱입니다.

## 기능

- 식물 사진, 이름, 종류, 위치 저장
- 상태 기록: 좋음, 보통, 주의
- 마지막 물 준 날과 분갈이 날 관리
- 식물 검색과 상태 필터
- 휴대폰 카메라/사진첩에서 사진 추가
- 백업 파일 내보내기와 불러오기

## GitHub Pages로 쓰기

이 폴더를 GitHub 저장소에 올린 뒤, 저장소 설정에서 GitHub Pages를 켜면 휴대폰 5G에서도 접속할 수 있습니다.

저장 데이터는 로그인 없이 각 브라우저 안에 저장됩니다. 휴대폰을 바꾸기 전에는 앱 안의 `백업` 버튼으로 파일을 내려받아두세요.
